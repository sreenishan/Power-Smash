# Changelog

All notable changes to Power Smash are recorded here, newest first. The format follows [Keep a Changelog 1.1.0](https://keepachangelog.com/en/1.1.0/). The project has no public release yet, so version numbers (which would follow [Semantic Versioning](https://semver.org/spec/v2.0.0.html)) start at the first public go-live (gate G1 in `docs/BUILD_PLAN_PHASE1.md`).

Update this file in every vertical slice (spec section 0 rule 11). Write for the owner: say what changed for them, not which file moved.

## [Unreleased]

Milestone M0 (setup, the Windows 10 smoke-test gate G0, parser fixtures) is partly done and Milestone M1 (the money pages and the enquiry funnel) is built and reviewed, both as of 2026-10-21. As of 2026-10-22 the code for Milestone M2 (archive engine: sync, parser, identity, database, public pages, minimal admin) and a large part of Milestone M3 (admin screens, sponsor placements, QR posters, two new forms) is also built and reviewed by three reviewers (41 findings), but only against pretend services and a local database. Three independent reviewers found 58 problems in M1 and the fixes are in (the list is under "Fixed"); a retest confirmed 48 fixed, 1 accepted, 4 waiting for an owner decision and 5 still open, and raised 15 new minor findings (`docs/SPEC_AUDIT.md` section 9). The "Not done yet" list at the end says what is still waiting for you or for a deploy.

### Changed

*Hosting moved from Cloudflare Workers to Vercel, 2026-10-22 (owner decision, D-097); nothing was ever deployed on Cloudflare, so nothing is migrated*

- **The website will be hosted on Vercel.** The plan, decision records and owner steps are rewritten (OT-02 is now the Vercel account and project, not a Cloudflare deploy key).
