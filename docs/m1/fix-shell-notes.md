## 5. How to run the build tests, and the manual render check

- `tests/build/*.test.ts` read `dist/client` and are skipped when it does not exist. **CI currently runs `npm test` BEFORE `npm run build`** (`.github/workflows/ci.yml`, order check, test, build), so on a clean runner these tests are skipped in the test step. The brief assumed the build comes first; it does not. To make them count, the lead (infra owns `ci.yml`) should add after the Build step: `PS_REQUIRE_DIST=1 npx vitest run tests/build` (the variable turns a missing folder into a failure instead of a skip). Locally: build first, then `npx vitest run tests/build`.
- `node scripts/with-lock.mjs heavy -- node tests/build/verify-supplied.mjs` (about 30 seconds): copies the sources to `tmp/verify-shell` (git-ignored, removed afterwards), fills in fictional owner data, runs the real build there and asserts on the HTML. Not part of `npm test` (a build inside a test is too heavy), run it after changing `OwnerSection`, the tournament page or `AudienceFigures`.

## 6. Proposed decisions (for the lead to put in DECISIONS.md)

**P-7 One URL form: internal pages end with a slash.** Context: pages build to `x/index.html`; Cloudflare's default `auto-trailing-slash` serves `/x/` directly and redirects `/x` with a 307 (verified in the official docs, 2026-10-21); review B-15 and C-21 found canonical with a slash and every link without. Decision: every internal page URL (links, breadcrumbs, canonical, `og:url`, JSON-LD, sitemap-style references) is written through `path()` / `absoluteUrl()` in `src/lib/urls.ts`; `ROUTES` lists the pages; endpoints (`/api/*`, `/go/*`, `/cdn-cgi/*`) and files never get a slash. Consequences: no redirect per click; tests in `tests/site/{urls,links}.test.ts` and `tests/build/links.test.ts` keep it so. Supersedes shell deviation 9 and request 1 of `shell-notes.md`.

**P-8 Hidden-section marker contract.** Context: D-034 hides optional sections; the release gate could not list them (B-8, C-3). Decision: every `OwnerSection` call site (and the wrapper components `SponsorStrip`, `FaqList`) passes a unique kebab-case name (at most 40 characters); a hidden section leaves `<template data-owner-hidden="name"></template>`; a blank or whitespace-only string, an empty array, null, undefined, false, 0 and NaN count as "not supplied"; an invalid name throws at build time; a missing name leaves an unnamed marker that the gate lists as "(unnamed)" and the build test rejects. Consequences: `npm run check:placeholders` lists what is waiting for the owner; adding a section means adding a name.

**P-9 Deferred package inclusions.** Context: R-ALLOWED-CLAIMS. Decision: an inclusion that needs a feature that does not exist yet carries `availableFrom` (`'M2'` or `'Phase 3'`) and is never shown; pages read inclusions only through `publicInclusions()`. The marker is removed only when the feature exists and the owner agrees. Consequences: the final packages remain the owner's decision (OT-20, OT-22); D-024's re-led offer is still unapplied.

**P-10 Payment wording is the owner's.** Decision: no page states when payment details are sent unless `site.paymentNote` (owner-worded) is set; the line is hidden until then. Consequences: OT-20 gains the question in section 1.

**P-11 Audience figures are dated or absent.** Decision: `<AudienceFigures />` never shows an undated figure; values are the owner's own text from YouTube Studio; with nothing supplied it shows a `<Todo>` (G1 input OT-12). `site.audience.asOfDate` and `site.channel.asOfDate` are ISO dates the release check can age with `daysBetween()`.

**P-12 (needs the owner, amends P-4 against D-016 item 5) Owner-stated channel figures.** Context: D-016 item 5 says no stored statistic, subscriber count included, is kept more than 30 days and long-term figures come from the owner's monthly entry labelled "as of". Shell P-4 argued the clock does not apply to owner-stated rounded figures but never recorded it. Decision proposed: the clock applies to API data only; owner-stated figures are allowed with a visible "as of" and an ISO `asOfDate`; the release check warns after 35 days and fails the strict build after a further agreed grace period; the owner re-states them monthly (OT-12). Consequences: if the owner does not agree, hide the counters after 30 days instead.
